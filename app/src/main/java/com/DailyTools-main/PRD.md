APP: DailyTools

Goal:
Provide fast, local, no-login PDF utilities in the browser.

Platform:
Web only.

Must-have tools (v1):
- Merge PDF
- Split PDF
- Compress PDF
- Images to PDF
- PDF to Images

UX Rules:
- App opens directly to home (no login)
- Perfect dark and light mode
- Accent color used on buttons and icons
- Responsive for desktop and laptop

Screens:
1. Home: grid of tool cards
2. Tool page: file picker + action button
3. Processing state
4. Result screen with download

Non-goals (not in v1):
- OCR
- Sign PDF
- Password protect
- Accounts
- Cloud storage
